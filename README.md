## ⚠️ 请先读这一段

本仓库包含对历史人物、制度、国家、宗教与法律体系的**定级判定**。
这些判定是**方法论演示**——目的是展示一套判定规则如何运作，
而不是对任何历史主体、信仰传统或现存国家作政治或道德审判。

三点说明：

1. **这不是政治评判。** 案例库不含任何中国现当代政治内容，也不对任何现存政权作评价。
2. **这不是信仰评判。** 涉及宗教的案例是对其**社会历史影响**的分析，不涉及教义真伪判断。
3. **判定随视角而变，且这是设计意图。** 同一主体在不同视角下可得出不同结论，两者都有效。
   唯一不随视角改变的是**底线判定**（非战斗人员生命不可侵犯）。

如果只截取单个案例而不带这段说明，很容易被误读。请在引用时附上运行规则或本页面。

## 核心架构

### 四个维度（独立定级，不做综合打分）

| 维度    | 对应  | 回答的问题          | 不承担什么  |
| ----- | --- | -------------- | ------ |
| **慈** | 动机  | 是否以他人福祉为旨归？    | 是否成功   |
| **秩** | 有效性 | 是否形成了运转中的秩序？   | 秩序是否正当 |
| **博** | 认知  | 是否穿透到深层结构？     | 是否落地   |
| **工** | 行动  | 是否造出了超越创造者的东西？ | 是否善意   |

**分维度独立定级（A3）**：不做综合打分，单一维度达最高层级即为该层级。
**短板原则（C3）**：慈、秩、博取最小值（恶行不被善行掩盖），工取最大值（成就不被崩塌抹杀）。

### 两条公理

- **A2 绝对人道底线**：非战斗人员的生命安全与基础财产不可侵犯。
  **这是公理，不是概率**——先验不得覆盖，损益不得折抵。
- **A3 分维度独立定级**：不综合打分，拒绝平均主义。

### 五步法

```
1 无罪推定 → 2 事实证伪 → 3 身份适配 → 4 休谟抉择 → 5 分级负反馈
```

### 相对在输入，绝对在底线

- **可争论的**：文化视角、史料来源、归因系数
- **不可覆盖的**：底线判定，由**不变量检验**保证跨视角一致，分歧即报错

### 关于 318/318，必须说清楚

**口径说明：全库 318 例复算一致率 318/318（172 主案例＋139 十九世纪＋7 算法治理），另有 6 例演示案例一致率 6/6。论文口径只引用 172 例主案例。**

**这个数字只证明内部一致性，不证明外部有效性。**

案例库中的维度定级由作者预先给定，引擎证明的是「规则被忠实执行时能复现这些定级」。
它**不能**证明独立评判者会给出相同定级。

外部有效性需要**评判者信度实验**，方案见 `docs/INTER_RATER_PLAN.md`，尚未实施。
**这是本项目最大的开放问题。**

## 已知局限（诚实标注）

1. **维度定级是人工输入** → 需评判者信度实验
2. **历史计量数据有争议** → 人口、年限取自主流史学，本身可争论
3. **A2 是论证而非推导** → 它是规范起点，不是定理
4. **参数是经验阈值，非解析解** → 在实测稳定带内取值，非最优解
5. **幸存者偏差** → 案例库只含被历史记录者，不适用于评价普通人
6. **不评价意识或本意** → 评判的是证据，不是人心

### 什么会推翻这个框架

- 若独立评判者按规则的一致性**不高于**只给维度定义的对照组 → 判定规则是装饰性的
- 若底线判定在不同视角下出现实质分歧 → 不变量不成立，核心架构主张崩塌
- 若在稳定带内对**新案例**高度敏感 → 稳定性是案例集假象
