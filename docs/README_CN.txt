心秩学 · 慈秩博工 (四维三层五步法 )

一句话：不做综合打分，只做分维度独立定级。
先立秩序，再谈善意；先过底线，再谈趋势。

要的不是最后一个分数——比较分数没有意义。
要的是能够复盘，吸取经验，明得失，知进退。

【一条元规则】

M0 明得失、知进退
   目标不是考古复原，是复盘。
   世界观：秩序＝互利共赢
   价值观：体验（博）· 创造（工）· 奉献（慈）
   → 所以先验有偏是特性，不是缺陷。


【四条公理】

A1 客观唯物主义
   物质决定意识；真理与大势客观，个人认知有限。
   → 所以：不预设恶意（无罪推定）、不计量预言（只处理已知）。

A2 绝对人道底线
   非战斗人员的生命安全、基础财产不可侵犯。
   这是公理，不是概率——先验不得覆盖，损益不得折抵。
   → 政治家受约束，思想家也受约束，没有人能例外。

A3 分维度独立定级
   不综合打分，单一维度至圣即至圣。拒绝全盘否定，拒绝平均主义。
   慈＝动机 | 秩＝有效性 | 博＝认知 | 工＝行动
   → 褒奖做得好的维度，不等于褒奖这个人。
     动机不对由慈承担，加上休谟法则足以让总评很差，
     不必在单一维度上画蛇添足。

A4 此时此地
   以当前时点、此地视角评判；国籍民族时代风俗全部显式标注。
   → 否则我们怎么会得出"奴隶制不正确"这种结论？


【四维三层】

          普世版·内省修心   精英版·主动担当   至圣版·博学笃行
   慈      慈以待人          慈以护民          慈以润世
   秩      秩以循规          秩以立规          秩以定纲
   博      博以明辨          博以求知          博以探源
   工      工以笃行          工以精业          工以造物

   另两档：无（0）＝确凿的主动背离；地板＝降至0档且无任何维度达精英。

   维度优先级：秩 ＞ 慈 ＞ 博、工（博与工独立，可一高一低）


【五步法】

前置：无罪默认合格。无实证有害，默认四维达标。

第一步 无罪推定    —— 默认普世层信任，有实证方可降级
第二步 事实证伪    —— 区分本能（自私）与恶行（蓄意破局）
                      秩破局三分：恶性／救济型／价值挑战
第三步 身份适配    —— 身份 × 权责 × 时代，允许分段评价
                      慈取min（恶行不被掩盖），秩博工取max（成就不被抹杀）
第四步 休谟抉择    —— 贡献与破坏分开计量，破坏加权1.5倍
                      （痛苦不对称：让100万人过好，不抵消让10万人惨死）
第五步 分级负反馈  —— 常规靠制度制衡；极端救世仅在慈秩双归零时启用

   入世菩萨心肠，出世霹雳手段。
   先做阎王重塑互利秩序，再修慈悲回归善意初心。


【十一条推论】（全部由公理推出，不是新增规则）

C1  无罪推定      ← A1     证据越不可靠越难定罪
C2  只处理已知    ← A1     "长期看是好的"不进入计量
C3  min 原则      ← A3     慈秩博取短板，仅工看总量
C4  褒奖权归各维度 ← A3     不在单一维度叠加道德评价
C5  禁止双重惩罚  ← A3     同一事实不判两次
C6  主体分离      ← A3     政权／遗产分开，人担罪制存功
C7  准入与地板    ← M0+A3  入口筛：无创造与贡献者不入体系；
                           出口筛：有维度达精英者不判地板。同一原则两面
C8  降工规则      ← A3     缺失负反馈设计 → 工降一档（造出来，但活不过自己）
C9  视角相对·底线绝对 ← A4+A2  英雄与侵略者可以并存，底线不可变
C10 分段内独立身份适配 ← A3  身份在分段间变化时，各段按该段身份定标
C11 贡献以受益对象计 ← A1  贡献以"收益留在谁手里"计量，非活动规模


【一句话记住它】

无秩之慈是软弱的，无慈之秩是冰冷的，
无霹雳手段的慈悲是会被吃掉的。

—— 相对在输入，绝对在底线。

一、公理详解
──────────────────────────────────────────────────

A1 客观唯物主义
   唯物：物质决定意识；物质积累到临界点引发质变，意识随之涌现。
   客观：真理与历史大势客观存在、不以个人意志转移；
         但个人认知有限，永远只能观测到局部。
   推论（认识论）：律法与道德是特定物质条件下的主观建构，
         随历史大势演变，不具备超越时代的客观性。
         故评价人物须置于其所处大势；
         评价大势，则以其是否增进互利秩序为准。

A2 绝对人道底线
   触发：治理性／制度性剥夺（奴隶制、连坐、制度性徭役致死等）
   不触发：战时暴行、个人暴行 → 走慈维度常规判定
   后果：慈归零 ＋ 降一档。严重度不分级，由第四步损益对冲体现。

   验证：纳粹德国（底线击穿＋损益对冲＝降2档）→ 普世
         美国宪法、商鞅（底线击穿降1档）→ 精英
         董卓（秩无、工无）→ 地板
   顺序正确，且是规则自然算出的，不是特设的重罪条款。

A3 分维度独立定级
   四维分工：
     慈＝动机   褒奖出发点是否指向群体福祉，不承担"有没有做成"
     秩＝有效性 褒奖秩序是否真在运转，不承担道德判断
     博＝认知   褒奖洞察深度，不承担"有没有落地"
     工＝行动   褒奖"造没造出来、活没活下来"，不管道不道德

   至圣的判定条件：
     慈至圣：理念／行为指向文明级群体福祉（看初心，不需成功）
     秩至圣：搭建传世制度框架，福祉与秩序可长期存续
     博至圣：自圆其说 ＋ 不违背可验证事实 ＋ 形成体系性认知
             （与别种学说冲突是必然，不因此扣分）
     工至圣：突破范式 ＋ 改变运行逻辑 ＋ 成果长期存续被验证有效
             （不管道不道德）

   慈看初心，工看落地——这解决了思想家的判定难题：
   提出理念本身就是行为，其内容决定慈；是否被践行决定工。
   由此确立：心秩学的慈是动机论的，工是结果论的。
   乌托邦慈至圣而工普世——所以慈至圣不需要成功。

A4 此时此地
   关键论证：若以行为发生时的标准评判，奴隶制永远正确
             （当时多数人认同它）。只有站在此地此刻，
             才能判定它击穿底线。
   但"此时此地"是移动的——这恰恰证明底线是进化的，
   与"律法道德是主观建构"自洽。


二、主体类型映射（C6 主体分离的展开）
──────────────────────────────────────────────────

主体    四维判据
──────────────────────────────────────────────────────────────
人物    慈=利他行为  秩=秩序建设  博=认知探源  工=落地成果
制度    慈=普惠程度  秩=秩序框架  博=设计深度  工=存续时效
思潮    慈=理念利他(看初心)  秩=是否成秩序框架  博=探源深度  工=被践行程度
法律    慈=min(对内公正,对外底线)
        秩=覆盖力·可预期性·多数认同·司法独立
        博=法理穿透力  工=存续×执行率×纠错效率
法系    慈=同上  秩=秩序生成方式的效力  博=范式是否理解人性  工=典范影响×存续
国家    慈=min(民生,对内公正,对外底线)
        秩=min(局部,全局,对外主权)
        博=min(地缘,生产力)
        工=治理年限×效能×自我修复
组织    慈=min(内部公平,外部普惠)
        秩=商业/行业秩序重构  博=行业与生产力边界认知  工=产品与商业成果

三处要点：
① 法律的"多数认同"归秩不归慈。
   多数人支持的法律完全可能是恶法（美国南方奴隶制、纳粹纽伦堡法案、
   印度种姓制度，当时都被多数人认同）。若用它撑慈，A2 就废了。
   多数认同说明的是"秩序立不立得住"，那是秩的事。
② 法律的工必须乘执行率。纸面法律 ≠ 活法。
③ 国家的博 = 地缘 × 生产力，是乘性不是并列。
   生产力变革会重塑地缘重要性：铁路让内陆崛起，海运让沿海崛起，
   火器改变农耕与游牧的力量对比。
   清朝的失败不是"闭关"（地缘选择），
   而是没识别出工业革命正在重塑国家能力边界。


三、三条最容易被误解的推论
──────────────────────────────────────────────────

C3 min 原则——同一个 min 函数，三种依据：
   慈取 min：道德逻辑，恶行不被善行掩盖
             （福特：外部普惠至圣、内部反工会精英 → 慈精英）
   秩取 min：有效性逻辑，秩序的完整性
             （北宋：对内300年无藩镇、对外称臣纳贡 → 秩精英）
   博取 min：认知逻辑，盲区不被洞见掩盖
             （清朝：地缘与生产力双弱 → 博全库最低）

C5 禁止双重惩罚——三处生效，常被漏掉第三处：
   ① 慈已归零 → 工不再因同一事实降档（尼采、商鞅不降工）
   ② 底线危害已由底层条款处理 → 不重复计入第四步
      （但非底线危害仍须计入）
   ③ 分段评价时某段的恶性破局 → 只标注标签，不重复降档

C7 准入与地板——哲学含义比技术含义更重要：
   "但凡能进到心秩学体系被分析的事物，都不太可能是地板。"
   能被历史记住、值得被分析，本身就说明至少一个维度有可取之处。
   董卓因此从地板升为精英（破局型·慈为无·分段崩塌）——
   这不是翻案，是承认可复盘的事实。


四、局部秩 vs 全局秩
──────────────────────────────────────────────────

秩 = min(局部秩, 全局秩)，差距 ≥ 2 档标注"秩失衡·不稳定前兆"。

主体              局部秩              全局秩              诊断
──────────────────────────────────────────────────────────────
李鸿章            至圣(淮军/北洋)      精英(地方化瓦解中央)  差1档
湘军·淮军体系     至圣(地方治理高效)   普世以下(中央财权旁落) 差3档 → 强失衡

这解释了晚清为什么"不缺能臣"却仍然崩溃：
局部秩序的总和，不等于全局秩序。


五、输出格式（复盘导向）
──────────────────────────────────────────────────

不再只给一个定性，而是"四维各自标签 + 一条统一标签"：

    【北宋】王朝
      慈：至圣（慈=动机，慈以润世）
      秩：精英（秩=有效性，秩以立规） · 短板=对外主权（燕云未复、称臣纳贡）
      博：精英（博=认知，博以求知） · 地缘=弱：燕云十六州未收复
                                    · 生产力=强：交子/活字印刷/火药
      工：精英（工=行动，工以精业） · 无自我修复 · 效能=经济高效能，军事低效能
      ▶ 统一标签：至圣（残缺型·部分兑现）

统一标签用于归类，四维标签用于复盘——复盘才是这套体系的初衷。


六、判定算法
──────────────────────────────────────────────────

贝叶斯前置（先验·A4）→ 五步法（似然修正）→ 决策树（后验输出）

先验来自主流历史共识，有偏可接受——目标不是考古复原，是明得失。
但 A2 绝对人道底线是独立于概率流程的硬截断器，先验不得覆盖。

置信度 < 0.6 时，定罪比值按 √置信度 折减（C1 疑罪从有利）：
不是给好人打折，是给不可靠的证据打折。

七、体系内核
──────────────────────────────────────────────────

传统认知：手握权力，故而可以施行仁慈。
本体系认知：拥有制衡手段、兜底能力、秩序重塑实力，方配谈仁慈善意。

无霹雳手段护体的菩萨心肠，容易沦为博弈中的弱势善意，被侵占与消耗。
世道崩坏、秩序失守时，必先以强力重建规则、稳住底盘，
再谈互利共赢与普惠善意。

相对在输入，绝对在底线。
正反馈决定你能走多快，负反馈决定你能走多远。
而负反馈不只是对错的补救——它更是工的构成要件（C8）。
这是从"有没有成果"到"成果能不能活"的跃迁。

—— 相对在输入，绝对在底线。
