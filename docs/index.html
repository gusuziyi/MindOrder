1第一步 · 无罪推定：先给四维定级

默认四维全部达标，不预设恶意、不主观揣测。只有拿到明确实证，才在第二步降某一维。
维度优先级 秩 ＞ 慈 ＞ 博、工；博与工相互独立，可一高一低。

2第二步 · 事实证伪：区分本能与恶行

拿客观事实去核对上面给的层级。人性自私是本能在，合理利己、时代局限、改革阵痛都不算问题； 只有蓄意、大幅、主动地破坏秩序，才降级。

A2 绝对人道底线

秩破局三分仅当秩为「无」时生效

至圣条件校验博、工要拿至圣须同时满足

慈的行为证据看可验证的行为，不靠动机推断

3第三步 · 身份适配：时间动态三维权衡

同一套标准不能量所有人。结合主体身份、社会权责、时代阶段匹配专属标尺， 执政者、思想家、制度各有各的判法。
两项都选才生效，取两者中低的一档。相差 2 档以上标注「秩失衡」——局部强而全局弱，是崩塌前兆。

4第四步 · 休谟抉择：贡献与破坏计量

贡献与破坏分开计量、永不相减；对冲时破坏项加权 1.5 倍（痛苦不对称性）。只处理已发生的事实，预言与「长期看是好的」不进入计量。

5第五步 · 分级负反馈：严控极端手段边界

这一步没有可调参数——它是输出端的规矩，决定「发现问题之后怎么办」。
常规治理阶段 以温和制衡为主：律法合同、舆论监督、分权制衡、谏官体系、制度约束，搭起长效风险围栏。个人可锤炼硬实力、建立物理威慑，避免善意被肆意霸凌。
极端救世阶段 仅当慈、秩双双归零，且制度全面失灵、人心全域崩坏、社会秩序彻底崩塌时，方可启用极端矫正手段。恪守：入世菩萨心肠，出世霹雳手段——先做阎王重塑互利秩序，再修慈悲回归善意初心。

四条公理

不可再分，一切规则的源头。五十余条修订在 v3.7 中收敛于此。
A1
客观唯物主义
物质决定意识，物质积累到临界点引发质变；真理与大势客观存在，但个人认知有限，只能观测局部。

推出：C1 无罪推定、C2 只处理已知
A2
绝对人道底线
非战斗人员／无现实威胁个体的生命安全、基础财产不可侵犯。
这是公理，不是概率——先验不得覆盖，损益不得折抵。

推出：C9 视角相对·底线绝对

十一条推论

全部由公理推出，不是新增规则。删掉它们公理仍在，写上它们误用减少。
编号推论内容源自
C1无罪推定默认普世层基础信任，须有实证方可降级。证据越不可靠越难定罪← A1
C2只处理已知只计量已发生的事实；预言与「长期看是好的」不进入损益← A1
C3min 原则慈、秩、博取短板：恶行不被善行掩盖，盲区不被洞见掩盖。仅工看总量← A3
C4褒奖权归各维度四维各自褒奖各自的事，不在单一维度上叠加道德评价← A3
C5禁止双重惩罚同一事实不判两次：慈已归零则工不再罚；底线危害不重复计入第四步；分段破局不重复降档← A3
C6主体分离政权／遗产分开判，个人／制度分开判。人担罪，制存功← A3
C7准入与地板无创造与贡献者不入体系——能被分析者，皆有可吸取之处。同一原则的一体两面：入口筛（无贡献者不入体系）与出口筛（有精英以上维度者不判地板；地板＝降至 0 档且无任何维度达精英）。← M0
C8降工规则缺失负反馈设计的造物不算完整工（防扭曲锁缺失）← A3
C9视角相对·底线绝对输入可随视角而变（英雄／侵略者并存），底线不随视角改变← A4+A2
C10分段内独立身份适配身份在分段间变化时（周处：无职青年→朝廷命官），各段按该段身份定标。min 负责「恶行不被善行掩盖」，C10 负责「恶行按发生时的身份恰当定级」← A3
C11贡献以受益对象计贡献须以「收益留在谁手里」计量，而非以活动规模（里程、产量、招生数）计。滇越铁路规模很大但收益外流← A1
